# 开工前介绍：dsh-chem（施工交底，终版）

写于 2026-10-30。这一版把前面的反复都收敛成定稿：**venv 强制、扩展功能不砍、只给 DSH 用、ADMET 不装**。
文档、架构、工具面、里程碑、验收都在这里；开工后按 §7 推进，不再改方向。

## 0. 一页速览

| 项 | 值 |
|---|---|
| 是什么 | 一个 DSH 插件：把本机的化学计算与绘图能力接到 agent 手上 |
| 给谁用 | 本科生、研究生、任课老师（Windows + ChemDraw 机器） |
| 形态 | 宿主插件（13+2 工具）+ 右栏面板 + Python 引擎 |
| 运行时 | **独立 venv**（`%LOCALAPPDATA%\dsh-chem\runtime`，约 300 MB） |
| 联网 | 只有 `chem_lookup` 出网，结果缓存并标注来源 |
| 工期 | 约 62 小时 ≈ 8 个工作日 |
| 不做 | 量子化学、分子对接、真实机械臂、红外/紫外预测、ADMET-AI |

## 1. 用户与场景

四个真实流程，决定了工具面的形状：

1. **交作业**：把一张截图或一个名字变成结构 → 核对分子量 → 出一张能贴的图。
2. **做毕设**：导入 300 个分子 → 描述符表 → 类药性与结构警示筛选 → 相似性聚类 → 代表性结构联系表。
3. **写论文**：反应式与路线图、机理箭头、期刊规格出图（PNG/SVG/向量 PDF/EPS/TIFF）、SI 表、HRMS 表征文字。
4. **上课/带课**：出题变体、批改、板图与标准曲线、把结构嵌进 Word/PPT。

## 2. 终版架构

\u0060\u0060\u0060
学生一句话
   ↓
DSH 会话 → agent → 工具调用 chem_*
   ↓
① 插件层  ~/.dsh/plugins/dsh-chem/        约 2 MB，进 git，可移植
     lib/index.js    15 个工具注册 + 参数校验
     lib/bridge.js   3 个端点（state / artifacts / call）
     lib/client.js   右栏面板（3 区：输入 / 出图 / 产物）
     core/chem/*.py  引擎源码（14 个模块）
     data/*.json     规则表（PAINS/BRENK/Lilly/安全/期刊规格）
     skills/chem/    给 agent 的使用说明
   ↓ 一个工具 = 一次子进程 = 一次 JSON
② 运行时层  %LOCALAPPDATA%\dsh-chem\runtime\   约 300 MB，机器本地
     独立 venv：RDKit / sklearn / scipy / PyMuPDF / Pillow / docx / openpyxl
   ↓
③ 外部能力  ChemDraw（cdx / Office 内嵌 / EPS）· KingDraw（兜底）· 本地 OCSR（molvec + DECIMER）
\u0060\u0060\u0060

**为什么 venv 不省**：DSH 自带 Python 会随宿主升级变化，全局 Python 会被别的项目改动；
只有独立 venv 能保证"今天能算出的数，半年后还是同一个数"。体积换确定性，值。

## 3. 工具面（15 个）

| 工具 | 做什么 | 引擎 | 依赖 |
|---|---|---|---|
| `chem_parse` | 名称/CAS/缩写/截图/序列 → 结构（OCSR 双引擎投票） | OPSIN + molvec + DECIMER | venv |
| `chem_clean` | 体检 / 规范化 / 互变异构 / 药化过滤 | RDKit | venv |
| `chem_draw` | 分子图 / 反应式 / 机理箭头 / 联系表；PNG·SVG·PDF·EPS·TIFF | RDKit + PyMuPDF + PIL（EPS 走 ChemDraw） | venv + 可选 ChemDraw |
| `chem_props` | 描述符、分子式、DBE、精确质量、类药性 | RDKit | venv |
| `chem_calc` | 配平、投料、产率、HRMS/元素分析文字、板图与稀释 | 纯 Python | venv |
| `chem_compare` | 指纹、相似性、MCS、骨架、聚类、SAR 表、MMP | RDKit（+ mmpdb 可选） | venv |
| `chem_table` | 批量描述符表、数据清洗、IC50 四参数拟合 | pandas + scipy | venv |
| `chem_db` | 本地库：导入 / ID 查 / 子结构查 / 相似查 / 去重 | SQLite + RDKit | venv |
| `chem_ml` | 训练 / 骨架切分 CV / 预测 / 指标 / 重要性 | sklearn | venv |
| `chem_enum` | 变体、立体枚举、组合库、Markush/R 基 | RDKit | venv |
| `chem_retro` | 单步断键（rdchiral）+ 多步搜索（AiZynthFinder，可选组） | rdchiral / AiZynthFinder | 可选组 |
| `chem_exam` | 批改、出题、答案断言 | RDKit + OCSR | venv |
| `chem_spectra` | NMR 处理与寻峰、质谱谱库匹配、分子式反推 | nmrglue / matchms | 可选组 |
| `chem_office` | Word/PPT 内嵌可编辑 ChemDraw 对象、SI 表 | ChemDraw COM + docx/pptx | ChemDraw |
| `chem_vendor` | `.cdx`/`.cdxml` 读写与合并拆分、EPS、预览、收工关窗 | ChemDraw / KingDraw | ChemDraw |

**分子识别能力不减**：双引擎投票 + MolScribe 第三票 + 多候选 + 置信度 + known-fail 清单。

## 4. 运行时与依赖

| 组 | 内容 | 何时装 |
|---|---|---|
| core | RDKit、numpy、pandas、scikit-learn、scipy、PyMuPDF、Pillow、python-docx、openpyxl | 必装（约 300 MB） |
| retro | rdchiral、AiZynthFinder | 可选 |
| spectra | nmrglue、matchms | 可选 |
| similar | mmpdb、fpsim2 | 可选 |

`bin/setup.py` 流程：找 Python（DSH 自带 3.12 → 系统 3.10–3.13）→ 设 ASCII 临时目录 → 建 venv → 装锁定版本 →
写 `runtime.json`（解释器 + 每个包版本 + 时间）→ 跑自检（渲染一张图 + 算一次分子量）。

升级策略：`runtime.json` 里的版本是验收基准；换版本必须重跑全量验收，否则拒绝启动并提示重建。

## 6. 数据与网络

- 默认全本地；只有 `chem_lookup` 出网（PubChem/ChEMBL/Crossref）。
- 每次联网结果落缓存并标 `source` 与时间戳；断网时返回缓存或明确说"查不到"，**不编造**。
- 所有预测类数值（类药性、pKa 近似）在返回里标 `rule_based: true`。

## 8. 质量门禁

每个工具必须有确定性断言，说法与判据一一对应：

| 类型 | 判据 |
|---|---|
| 结构 | InChIKey 回读一致 |
| 规范化 | 输入 → 期望字符串完全相等 |
| 数值 | 与 RDKit 参考值误差 < 1e-6 |
| 渲染 | 像素尺寸、键长中位数、留白比例在阈值内 |
| 识别 | 固定图片 → 固定 InChIKey；失败样本进 known-fail |
| 配平 | 左右原子数差 = 0 |
| 整体 | preflight + 8 场景 acceptance 全绿才提交 |

## 9. 风险登记册

| 风险 | 影响 | 对策 |
|---|---|---|
| ChemDraw COM 抢焦点/卡死 | 打断用户操作 | 只在 4 个动作启动；超时强杀；调用前查实例；失败降级到 RDKit |
| 插件启动搞崩客户端（已发生） | 面板不显示 | client 全 try/catch、嵌套 inject、自报日志 |
| venv 300 MB | 换机器要重装 | setup 一键；离线 wheelhouse 可选 |
| DSH 自带 Python 建不了临时目录（已实测） | setup 失败 | 强制 TMP 到 ASCII 目录；失败回退系统 Python |
| 模型权重下载失败 | 识别通道降级 | molvec + DECIMER 双通道，任一可用即可投票 |
